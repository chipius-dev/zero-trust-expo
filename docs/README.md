# Knowledge Base & SDLC Documentation

Welcome to the central knowledge base for the **Agentic SDLC Template**. This directory contains all platform-agnostic engineering standards, Matt Pocock's 7 Phases workflow playbooks, and architectural records.

---

## 🗂️ Documentation Sections

### 1. [Matt Pocock's 7 Phases Workflows](file:///docs/workflows)
Step-by-step playbooks covering every stage of AI-driven software development:
- [01: Idea](file:///docs/workflows/01-idea.md) - Problem definition, user motivation, and backlog capture.
- [02: Research](file:///docs/workflows/02-research.md) - Targeted codebase exploration, API feasibility, and library comparison.
- [03: Prototype](file:///docs/workflows/03-prototype.md) - Disposable spikes and tracer bullets to de-risk unknown patterns.
- [04: PRD & Alignment](file:///docs/workflows/04-prd-and-alignment.md) - PRD creation, "Grill-Me" alignment, and shared design concepts.
- [05: Implementation Planning](file:///docs/workflows/05-implementation-planning.md) - In-repo roadmap management, vertical slicing, and ~100k token sizing.
- [06: Execution](file:///docs/workflows/06-execution.md) - Test-Driven Development (Red -> Green -> Refactor) and atomic coding.
- [07: QA & Verification](file:///docs/workflows/07-qa-and-verification.md) - Automated quality gates, code reviews, and loopback cycle.
