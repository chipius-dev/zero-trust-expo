# Say Hello Skill

This is a simple greeting skill for the zero-trust-expo environment.

## What it does

When invoked with `/say-hello`, this skill responds with:

```
Hello, Josh!
```

## How to use

Call this skill from any session:

```
/say-hello
```

The skill will greet the user (Josh) with a friendly message.
