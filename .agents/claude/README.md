# Claude Code & Projects Adapter

This adapter configures **Claude Code CLI** and Claude Web Projects for this repository.

---

## Usage

For Claude Code CLI, link `CLAUDE.md` to the repository root:
```bash
ln -sf .agents/claude/CLAUDE.md CLAUDE.md
```
Or run `bash .agents/sync-adapters.sh`.

For Claude Web Projects, upload [`AGENTS.md`](file:///AGENTS.md) and [`docs/`](file:///docs) as project knowledge documents.
