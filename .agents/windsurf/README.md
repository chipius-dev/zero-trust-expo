# Windsurf Adapter

This adapter configures **Codeium Windsurf** (Cascade & `.windsurfrules`) for this repository.

---

## Usage

Link `.windsurfrules` at the root of the repository to this adapter:
```bash
ln -sf .agents/windsurf/.windsurfrules .windsurfrules
```
Or run `bash .agents/sync-adapters.sh`.
