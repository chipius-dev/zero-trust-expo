# ITEM-0028: Define encrypted object and version TypeScript interfaces

## Why

The encrypted objects type is where the zero-trust boundary is most at risk. A
`type: 'password' | 'note' | 'document'` field on the server-facing interface
immediately reveals object semantics to the API. Any domain-semantic field in this
type leaks information at the API boundary regardless of how well the ciphertext
is protected.

## Scope

- `EncryptedObject` interface: `objectId: OpaqueId`, `accountId: OpaqueId`,
  `ciphertext: Uint8Array`, `keyVersion: number`, `sequenceNumber: number`,
  `createdAt: number`, `updatedAt: number`, `deletedAt: number | null`
- `ObjectVersion` interface: `versionId: OpaqueId`, `objectId: OpaqueId`,
  `ciphertext: Uint8Array`, `sequenceNumber: number`
- API contract types: `PutObjectRequest`, `PutObjectResponse`, `GetObjectResponse`,
  `ListObjectsResponse` — sequences and opaque IDs only, no domain fields
- Local expo-sqlite DDL: `encrypted_objects` and `object_versions` tables
  with `sequence_number` for optimistic concurrency and `deleted_at` for tombstones

## Out of scope

- Server SQL DDL — not part of this template
- Domain-typed subtypes of EncryptedObject (passwords, notes) — those live entirely
  inside the ciphertext payload, never in the TypeScript interface
- Full-text search or server-side filtering by content

## Constraints

- Blocked by ITEM-0024 (envelope spec determines the ciphertext and keyVersion shape)
  and ITEM-0027 (accounts types must exist for the accountId reference)
- Zero domain-semantic fields on any server-facing type — lint check must flag any
  field named `type`, `name`, `category`, or `label`

## Decisions and rejected alternatives

- Chose a unified `EncryptedObject` interface for all object types over a discriminated
  union per type because a union leaks type information at the boundary — the server
  must not know which union member it is receiving
- Rejected adding a `metadata` field for server-side search because any searchable
  metadata reveals content structure
